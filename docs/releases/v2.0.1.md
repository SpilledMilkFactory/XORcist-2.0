# XORcist 2.0.1

XORcist 2.0.1 is a presentation and distribution update to the C++20 networking, diagnostics, binary-data, and authenticated-file toolkit.

## Highlights

- Replaces the horizontal GUI tab strip with a responsive **12-tile dashboard**.
- Opens each category in an animated workspace with a close button and **Escape** navigation.
- Uses full category names, including removal of development-milestone labels from user-facing navigation.
- Improves vertical space usage and scrolling for tool results, including Binary Data Tools.
- Preserves the existing CLI commands, core calculations, and authenticated `.xorc3` file format.
- Organizes downloads into one signed-manifest archive per platform, plus a `SHA256SUMS` index.

The release provides `SHA256SUMS` for all five platform downloads. Each archive also includes a signed `RELEASE_MANIFEST.json` and associated Sigstore verification bundle. ## Verification and security

The release candidates are built and tested independently for the four Linux distributions and Windows x64, with regression tests, native dependency auditing, SPDX inventories and Sigstore provenance verification. A successful automated run is not a substitute for target-system installation and GUI acceptance checks; release publication follows those checks.

The original repeating-key XOR tools are educational transformations, **not secure encryption**. Authenticated-file operations use OpenSSL-backed AES-256-GCM, but XORcist has not undergone an independent cryptographic security audit. See [`SECURITY.md`](https://github.com/SpilledMilkFactory/XORcist-2.0/blob/v2.0.1/SECURITY.md).

## Source compatibility

Version 2.0.1 does not intentionally change CLI contracts, network algorithms, or the encrypted-file container. The published 2.0.0 release remains available in the release history.
